# 面談前アンケート（入力ページ）

産業医面談の前に記入していただく「面談前の生活・健康状態に関するアンケート」の入力ページです。

- `index.html` … 入力ページ本体（スマホ・PC対応。選択肢はタップ／クリックでレ点）
- `template.xlsx` … 回答ファイル（Excel）のひな形。判定（医師用）シートで疲労蓄積度を自動判定します
- `lib/jszip.min.js` … Excelファイル作成用ライブラリ（JSZip 3.10.1, MIT License）

入力内容は回答者の端末内だけで処理され、サーバーには送信・保存されません。
回答者は最後に回答ファイルを保存し、メール・LINE等で面談担当者へ送ります。
