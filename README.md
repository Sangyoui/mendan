# 面談前アンケート（入力ページ）

| ページ | URL | 内容 |
|---|---|---|
| 全項目版 | [https://sangyoui.github.io/mendan/](https://sangyoui.github.io/mendan/) | 1．〜9．（疲労蓄積度の自動判定あり） |
| 1ページ目版 | [https://sangyoui.github.io/mendan/short.html](https://sangyoui.github.io/mendan/short.html) | 1．〜5．のみ |

- 回答はアンケート用紙（Excel）と同じレイアウトのPDFになり、「LINE・メールなどで送る」で共有、または「PDFで保存する」で保存できます。
- Excel形式での保存も可能です（全項目版は「判定（医師用）」シート付き）。
- 入力内容は回答者の端末内だけで処理され、サーバーには送信・保存されません。
- どちらも1ファイル（`index.html`、`short.html`）で動きます。内蔵ライブラリ：JSZip 3.10.1（MIT）、html2canvas 1.4.1（MIT）、jsPDF 2.5.1（MIT）。
